# Poseidon - Calidad y Pruebas

Carpeta de informes reproducibles emitidos por el workstream `Poseidon Calidad y Pruebas` cuando una orden autorice persistirlos.

Los informes usan `docs/plantillas/REPORTE_CALIDAD.md`. Cada hallazgo debe identificar el commit exacto, alcance, entorno, evidencia y limites. Una sugerencia pasa primero por Poseidon Central y nunca autoriza por si sola un cambio funcional.

No guardar capturas, trazas ni respaldos pesados en Git. Playwright conserva artefactos de fallo fuera del versionado normal.
