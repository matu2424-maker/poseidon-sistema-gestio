# Modulo 06 - Diferencias de caja

## Objetivo

Controlar diferencias de efectivo y banco sin ocultarlas ni ajustar automaticamente.

## Reglas

- Diferencia efectivo = efectivo declarado - efectivo esperado.
- Diferencia banco = banco declarado - banco esperado.
- No modifican resultado economico.
- No mueven saldos automaticamente.
- Quedan visibles y auditadas.
- Encargado/admin deben gestionarlas.

## Acciones de gestion

- REVISADA: marca como revisada, no mueve dinero.
- RESUELTA: cierra el control como resuelto, no ajusta automaticamente.
- AJUSTADA: indica que habra ajuste definido aparte.
- ANULADA: anula el reclamo operativo, no borra auditoria.

## Obligatorio

- Elegir accion.
- Escribir observacion del encargado/admin.
- Mantener observacion original del cajero.
