Reglas locales:

- El layout define pantalla inicial, acceso local, barra superior, menu lateral y funcion activa.
- Evitar titulos repetidos entre barra superior y contenido.
- Los menus laterales se agrupan como desplegables cuando ayuda a ordenar funciones.
- No mover logica contable o de datos al layout; mantenerlo como orquestacion visual y navegacion.
